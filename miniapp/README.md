# 轻创微信小程序版

这个目录是轻创主站的原生微信小程序适配版，可直接用微信开发者工具导入：

- 导入目录：`miniapp`
- 当前状态：原生 UI 已适配，登录结构预留为微信登录
- 现阶段：使用本地存储演示校园服务流程，后续把 `wx.login` 的 code 发送到轻创服务端，完成正式微信登录与真实数据同步

## 当前页面

- 首页
- 校园服务
- 快递代取
- 旧书广场
- 零食快递
- 校园钱包
- 订单中心
- 我的
- 微信登录预留页

## 后续接入微信登录建议

1. 小程序端调用 `wx.login`
2. 把 `code` 发送到轻创服务端
3. 服务端调用微信 `code2Session`
4. 生成站内用户与小程序会话
5. 小程序保存服务端返回的 token/session key
6. 所有请求通过 `x-mini-session` 或 Cookie 调主站接口
